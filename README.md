# sofa disposable canary

This repository is a disposable consumer for the first sofa hosted delivery slice. The baseline intentionally has a failing greeting test; an approved issue should authorize changing only `fixture/greeting.go` so all cases pass. The issue and Project Ready transition must be created and approved by Kevin before the agent workflow is run.

The `sofa hosted E2E manual cleanup` workflow is an opt-in retirement path for a **superseded** hosted suite after its assertions and trusted result have been inspected. Run it on `main` with the original sofa PR head/base, disposable base, exact heads of `sofa-e2e/<suite>` and `sofa-e2e-result/<suite>`, candidate digest, and disposable draft PR number. The trusted observer report supplies the digest and draft PR identity; read both branch heads directly before the dry run. The first dispatch leaves `apply` false and checks ownership without writes. A second dispatch with the same inputs and `apply` true closes the owned draft PR and removes both refs with Git's exact-head lease. A changed head, altered workflow, mismatched result marker, unrelated tree edit, non-draft PR, ambiguous branch PR, or currently active suite fails closed. The command uses the existing coordinator environment and disposable publisher credential; candidate jobs receive neither.

Keep the current successful suite while its open sofa PR may be replayed. A prior suite becomes eligible when the sofa PR head/base or disposable base advances, or that sofa PR closes. If cleanup is interrupted after closing the PR or deleting the caller ref, repeat the same workflow inputs; it verifies the remaining owned resource before continuing. Do not use this workflow to delete an arbitrary branch or to clean a still-active suite.
